## Synthesis — Rules for Peak's Cartridges

### Article cartridge
1. Above-the-fold: eyebrow tag → H1 (number+outcome, e.g. "N Reasons X Choose Y," or curiosity-hook, e.g. "X Won't Y — Here's Why"), 8–14 words → optional 1-sentence subhead → hero photo → one CTA.
2. Bake a verified numeric proof point into the H1 or as a photo-overlay badge when one exists; otherwise place a press/credibility strip directly under the hero image.
3. Section order: Hero → proof strip (optional) → numbered-reason sections (photo + heading + ~40–70 words each) → repeat the same CTA text → guarantee/close.
4. CTA cadence: one CTA phrase, repeated verbatim at nav, mid-page, and close — never a second distinct phrase.
5. Never attribute copy to a named/credentialed persona ("Dr. X, MD") unless the person is real and verifiable.

### Product-page cartridge
1. Above-the-fold: short eyebrow → bold benefit headline (2–8 words) → one proof line (stars+review count, or a footnoted comparative stat) → price → one CTA beside/under a large product image.
2. Keep the product image dominant with generous negative space (Apple example: image occupies well under half the fold).
3. Section order: Hero → 3-item spec/icon row → gallery/variants → (tall pages) sticky bottom bar repeating price+CTA.
4. One CTA phrase; it may appear twice (nav+hero) but must be identical wording, never two different phrases.
5. Never ship a page with zero visible CTA (teenage engineering anti-pattern).

### Longform cartridge
1. Above-the-fold: eyebrow → benefit headline (5–9 words) → 3-bullet checkmark list or a proof-stat line → one CTA (offer kicker above or guarantee microcopy below) → supporting photo, optionally with a proof-badge overlay.
2. Section order: Hero → 3-stat proof row (bold number + sublabel) → body sections → repeat CTA.
3. One CTA phrase for the whole page — never render a second offer card or competing CTA (Roman anti-pattern).
4. Subhead/description length: 15–30 words; bullet items 3–8 words each.
5. Proof can live in two places at once (badge overlay + stat row) — both are legitimate, not redundant.

## Wireframes for Later — Quiz and Comparison Cartridges

### Quiz (type 04)
Two-screen pattern: **Screen A (pre-quiz marketing)** — nav with one quiz-CTA button → full-bleed lifestyle photo hero → benefit/brand-promise headline → subhead → proof row (stats or press logos) → single CTA naming the quiz + time estimate ("Start the 3 min quiz") → below fold: trust logos + "How it Works" 3-step visual. **Screen B (quiz start/Q1)** — stripped chrome (logo + Exit/Save-and-exit only) → split layout: photo one side, on the other: eyebrow → quiz title as H1 → 1-sentence time/expectation promise → single CTA ("Begin"/"Let's Go"/"Start →") → optional secondary "Resume" link → optional category-progress tab bar once mid-quiz. Carry forward: one CTA phrase per screen, always a stated time estimate, category name literal in the H1, no full nav on Screen B.

### Comparison (type 05)
Pattern: eyebrow "[Category] vs. [Alternative]" (literal) → H1 (literal repeat or punny reframe, ≤8 words) → subhead with one value-prop sentence → single CTA + 2-line risk-reversal microcopy → proof (star row or trust-logo wall) → (below fold, not captured here) comparison table → bottom-line/verdict section. For Peak: use generic-category framing only ("Infrared Sauna vs Traditional Sauna"), per the SweatDecks example — never name a competing sauna brand, and never include an EMF section. The editorial variant (Sun Valley Saunas) adds a sticky TOC sidebar, author byline+date, and a quiz-finder nav CTA — reusable for Peak's Learning Center, with the EMF/named-competitor sections excluded.
