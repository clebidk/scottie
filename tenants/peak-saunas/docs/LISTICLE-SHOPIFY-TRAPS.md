# listicle cartridge

Numbered "N reasons" pre-sell -- the format Peak has already shipped live at
`/pages/5-reasons-to-love-peak-saunas`. See `cartridge.md` for the voice/
structure contract, `schema.json` for the page.json shape, and
`template.html` for the Jinja + reveal-on-scroll motion (reproduced from
`reference/peak-listicle-lp/index.html`, adapted to `brand/base.css`'s
tokens).

Opt-in only: `adv run <input> --cartridges listicle` works today, but the
no-flag default random-3 pick (`adv/cli.py`'s `DEFAULT_CARTRIDGE_POOL`)
never selects it until Caleb approves it for the default rotation.

## `adv shopify-body`

```
.venv/bin/adv shopify-body out/<run-id>/listicle
```

Writes `shopify-body.html` (the page body only -- no `<html>`, `<head>`,
`<header>`, `<footer>`, `<nav>`) and `shopify-body.assets.json` (every image
the page references, with an intended Shopify Files CDN filename) next to
that run's `index.html`. Implemented in `adv/shopify.py` as a pure transform
of the already-rendered, already claims-gated `index.html` -- it makes no
Shopify API call and needs no network access at all.

## Shopify traps

(Copied from `reference/peak-listicle-lp/README.md`, which documents the
live reference this cartridge's motion and section rhythm were derived
from -- the same traps apply to anything generated by this cartridge.)

- The Aurora page template wraps `body_html` in `.container--small` with
  `.page__content{margin:3.2rem 0 0}`. Full-bleed comes from `:has()` rules
  at the top of `shopify-body.html` (`adv/shopify.py`'s
  `AURORA_FULL_BLEED_RULES`) that neutralise the container padding, the
  section spacing, the `.page__content` margin, and the duplicate
  `.page__title`. Removing them re-narrows the page.
- Editing a live page in Shopify admin's rich-text editor can strip the
  `<style>` block. Edit via the API only.
- The storefront serves page updates from several cache epochs. Verify with
  >= 8 pulls, not one.

## Publishing is not implemented

`adv shopify-body` only writes files to disk under `out/`. There is no
`adv publish`, no Shopify Admin API call, and no code path anywhere in this
harness that pushes `shopify-body.html` to peaksaunas.com. **This must never
be built or run without a packet stamped `ship` and Caleb's explicit
approval.**
