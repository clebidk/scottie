# Peak Saunas -- listicle library

Peak's side of the listicle winner library (cycle 73).

- `skeletons.yaml` -- Peak fill hints for the skeletons in
  `cartridges/listicle/skeletons/`: `angle_fit` words for the auto-pick and
  `item_hints` for the writer. Hints are angles, never facts.
- The winner the writer adapts is `exemplars/listicle/5-reasons-mini-sauna-live.md`
  (the live 5-reasons page); its skeleton is `classic-n-reasons`.
- Headline templates are the shared library, `cartridges/listicle/headlines.yaml`;
  Peak's include/exclude list goes in `tenant.yaml`
  (`cartridges.listicle.headline_templates`).
