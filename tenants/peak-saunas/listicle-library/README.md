# Peak Saunas — listicle library

Peak-first adaptations of `cartridges/listicle/skeletons/` (11 page maps) and `.../headlines/` (17 title swipes).

- Skeletons/headlines are tenant-neutral JSON under the cartridge.
- Each file’s `peak_saunas` block carries Peak angle fit, fill hints, and (for headlines) safe `example_fills`.
- Live DNA: `exemplars/listicle/5-reasons-mini-sauna-live.md` + `reference/peak-listicle-lp/` ↔ page `classic-n-reasons`.
- Stripped PDP DNA: `exemplars/product-page/fuji-2-person-product-page.md` ↔ page `simplified-pdp`.
- Mobile first-screen + consult box: `mobile-first-availability` ← [Noah Igler](https://x.com/noahiglerSEO/status/2108882995658514806) (screenshot in `skeletons/references/`).
- Headline swipe source image: `cartridges/listicle/skeletons/headlines/source-swipe.jpg`.

Default one-shot: `--skeleton classic-n-reasons --headline everyones-switching` (or auto-pick from ad angle). For consult/book angles on product-page, auto-pick prefers `mobile-first-availability`.
